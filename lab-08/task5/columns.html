Основи CSS Grid Layout

CSS Grid — двовимірна система розмітки: вона керує одночасно рядками і стовпцями. Ця сторінка зроблена за підходом mobile-first: базові стилі написані для телефону, а медіазапити з min-width додають розмітку для планшета та комп'ютера.

Зменшуйте та збільшуйте ширину вікна, щоб побачити три варіанти макета.
