## Контрольні запитання — короткі відповіді

1. **CSS Grid Layout** — двовимірна система розмітки (рядки + стовпці одночасно). Використовується для макетів сторінок, галерей, карток, дашбордів, складних сіток.
2. **Grid vs Flexbox:** Flexbox — одновимірний (або рядок, або стовпець), розміщує елементи «від вмісту». Grid — двовимірний, спочатку задається сітка, а елементи розміщуються в ній. Flexbox зручний для компонентів (меню, кнопки), Grid — для загального макета.
3. **Grid-контейнер** створюється через `display: grid` або `display: inline-grid`. `grid` поводиться як блоковий елемент (займає всю ширину), `inline-grid` — як рядковий (ширина за вмістом, стоїть у рядку з іншими).
4. **Терміни:** контейнер — елемент з `display: grid`; grid-елемент — його прямий нащадок; лінія — межа між рядками/стовпцями (нумерується з 1); трек — рядок або стовпець між двома сусідніми лініями; комірка — перетин одного рядка й одного стовпця; область — прямокутник з кількох комірок.
5. **`grid-template-columns` / `grid-template-rows`** задають кількість і розміри стовпців/рядків явної сітки, наприклад `200px 1fr 2fr`.
6. **`fr`** — частка вільного простору контейнера. `1fr 2fr` ділить вільне місце у співвідношенні 1:2 (після віднімання фіксованих треків і gap).
7. **`repeat(n, size)`** — повторює трек n разів; **`minmax(min, max)`** — трек не менший за min і не більший за max; **`fit-content(limit)`** — розмір за вмістом, але не більше limit.
8. **`auto-fill` vs `auto-fit`:** обидва створюють стільки треків, скільки поміщається. `auto-fill` залишає порожні треки (місце під них зберігається), `auto-fit` згортає порожні треки до 0, і наявні елементи розтягуються на всю ширину.
9. **`gap`** — відступ між рядками та стовпцями (не по краях). `row-gap` — лише між рядками, `column-gap` — лише між стовпцями; `gap: 10px 20px` = row-gap + column-gap.
10. **`grid-column` / `grid-row`** задають початкову і кінцеву лінію елемента: `grid-column: 1 / 3` (з 1-ї до 3-ї лінії), `1 / -1` (на всю ширину), `span 2` (на 2 треки). Так елемент переміщують і розтягують.
11. **Іменовані області:** елементу дають ім'я `grid-area: header`, а в контейнері «малюють» макет рядками `grid-template-areas: "header header" "sidebar main";`. Крапка `.` — порожня комірка.
12. **Вирівнювання:** `justify-items` / `align-items` — вирівнюють елементи всередині їхніх комірок по горизонталі / вертикалі; `justify-content` / `align-content` — вирівнюють усю сітку всередині контейнера, коли вона менша за контейнер.
13. **Явна сітка** — задана через `grid-template-*`. **Неявна** — треки, які браузер створює сам, коли елементів більше, ніж комірок. Їхній розмір задають `grid-auto-rows` і `grid-auto-columns`.
14. **`grid-auto-flow`** — напрямок автоматичного розміщення: `row` (за замовчуванням, рядок за рядком), `column` (стовпець за стовпцем — використано в завданні 6), `dense` — заповнює пропущені «дірки» меншими елементами (використано в завданні 3).
15. **Адаптивна сітка:** `grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));` — кількість стовпців змінюється сама залежно від ширини. Медіазапитами (`@media (max-width: 768px)` або mobile-first `@media (min-width: 768px)`) змінюють кількість стовпців, `grid-template-areas` чи `span` елементів.
